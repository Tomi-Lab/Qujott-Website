Qujott 1.2.0 最新版本
2026年11月

✨ 新功能與重點改善

  • 新增 UI 介面縮放（UI Scale）功能 (Windows):
    可於設定畫面中自由在 5 段倍率（80%、100%、120%、140%、160%）間調整應用程式整體的視覺大小。全面優化功能表、工具列與筆記清單在高解析度螢幕及筆記型電腦上的閱讀舒適度。
  • 與筆記內文字級和諧連動:
    與既有的筆記內文字級大小（A-- 至 A++）設定完美並存與連動，在大螢幕上也能享有最愜意的書寫視野。
  • 版面與邊界間距最佳化:
    徹底解決 80% 縮小顯示時的視窗外緣間隙，並讓高倍率下的按鈕排版更加寬敞易按。
Qujott 1.1.1
2026年10月

✨ 改善與問題修正

  • 檔案總管直接開啟檔案 (Editor Mode) 穩定性提升:
    強化從 Windows 檔案總管直接開啟 .md、.markdown、.txt 等外部檔案時的啟動流暢度與即時編輯體驗。
  • Editor Mode 專屬視窗位置記憶:
    獨立精準記憶與還原外部檔案編輯工作階段的視窗尺寸與座標。
  • 整體效能與視覺細節潤飾:
    全面優化細微顯示穩定度與敲擊文字的輕快節奏。
Qujott 1.1.0
2026年10月

✨ 重點更新與體驗改善

  • Qujott Pro 7 天免費試用 (Pro Trial):
    購買前可免費試用所有進階紙質色彩與氛圍主題（Atmosphere Scenes）長達 7 天。在設定中直接點選鎖定主題即可立刻啟用，無需註冊或預先綁定付款。
  • 應用程式內更新紀錄 ("更新紀錄"):
    在「設定 > 關於 (About)」畫面中隨時直接查閱最新版本的變更亮點。
  • 視窗幾何狀態與最大化還原最佳化:
    視窗大小、位置坐標、單欄檢視與最大化狀態在下次啟動時皆能滑順還原，完全消除跳動與閃爍。
  • 極速啟動效能優化:
    深入最佳化開機載入路徑，新增豐富體驗的同時依然維持本機優先的毫秒級閃電啟動。
Qujott 1.0.0
2026年9月

🎉 正式推出

  • 極簡思緒捕捉隨手筆記:
    本機優先運作、純粹安靜不打擾思考的專屬 Markdown 筆記空間。
  • 暫時收納 (Put Away) 與 稍後再看 (Revisit):
    不必刪除即可將筆記暫時收出視線，並在最合適的時機讓其自然重回頂端。
  • 自由自選的本機儲存目錄:
    以通用標準 Markdown (.md) 格式存放於電腦內任意指定資料夾，享有完整的掌控自由。
  • Qujott Pro:
    一次買斷解鎖專屬紙質質感與櫻花等氛圍主題的美型擴充套件。

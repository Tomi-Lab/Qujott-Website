# Qujott Official Website (MVP)

This repository contains the source code for the official website of **Qujott** — a quiet, local-first Markdown note application designed to capture thoughts before they disappear.

## Vision & Concept
- **Capture thoughts before they disappear.**
- **Write quietly. Keep them local. Meet them again when the time is right.**

## Structure
- `index.html` — Static HTML structure
- `style.css` — Minimal, quiet typography & CSS design system
- `.nojekyll` — Bypasses Jekyll build on GitHub Pages

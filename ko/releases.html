✨ 새로운 기능 & 개선 사항

  • UI 표시 배율(UI Scale) 기능 추가 (Windows):
    설정 화면에서 앱 전체 인터페이스 크기를 5단계(80%, 100%, 120%, 140%, 160%)로 자유롭게 조절할 수 있습니다. 고해상도 모니터와 노트북 등 다양한 환경에서 메뉴와 노트 목록의 가독성을 최적화합니다.
  • 본문 글자 크기와의 조화로운 연동:
    에디터 본문 글자 크기(A-- ~ A++) 설정과 자연스럽게 연동되어 어떤 디스플레이에서도 가장 편안한 크기로 작성할 수 있습니다.
  • 레이아웃 및 여백 최적화:
    80% 축소 표시 시의 윈도우 여백 현상을 해결하고, 고배율 확대 시에도 버튼 배치와 간격을 정돈했습니다.

✨ 개선 & 오류 수정

  • 탐색기 파일 직접 실행(Editor Mode) 안정화:
    Windows 탐색기에서 외부 .md, .markdown, .txt 파일을 열 때 직접 신속하게 불러와 열람·수정하는 실행 동작을 안정화했습니다.
  • Editor Mode 전용 윈도우 위치 기억 향상:
    외부 파일 편집 전용 창의 크기와 위치를 독립적으로 정확하게 기억하고 복원하도록 개선했습니다.
  • 전반적인 반응성 및 UI 완성도 향상:
    가벼운 타건감을 유지하고 세부 인터페이스의 안정성을 높였습니다.

✨ 주요 기능 & 개선

  • Qujott Pro 7일 무료 체험 (Pro Trial):
    잠겨 있는 유료 배경 테마와 풍경을 별도 가입이나 결제 없이 설정에서 바로 선택하여 7일 동안 무료로 사용해 볼 수 있습니다.
  • 앱 내 업데이트 소식 ("업데이트 내용"):
    설정 > 정보(About) 화면에서 최신 업데이트 내용을 앱 내에서 바로 확인할 수 있습니다.
  • 윈도우 상태 및 위치 복원 정확도 개선:
    창 크기, 좌표, 1패널 모드 및 최대화 상태가 다음 실행 시 깜빡임 없이 매끄럽게 복원됩니다.
  • 로컬 시작 성능 최적화:
    기능 추가 후에도 밀리초 단위의 경쾌한 로컬 퍼스트 부팅 속도를 유지하도록 최적화했습니다.

🎉 정식 출시

  • 생각을 바로 적는 미니멀 에디터:
    로컬 퍼스트로 가볍고 신속하게 작동하는 방해 없는 Markdown 메모 공간.
  • 치워두기(Put Away)와 다시보기(Revisit):
    메모를 삭제하지 않고 시야에서 깔끔하게 치워두었다가 필요한 때에 조용히 다시 꺼내보는 기능.
  • 자유로운 로컬 저장:
    PC 내 원하는 폴더에 순수 표준 Markdown(.md) 파일로 저장하여 완벽한 소유권을 보장합니다.
  • Qujott Pro:
    차분한 감성의 배경 테마와 정취 있는 풍경을 열어주는 평생 소장 라이선스.
